Project Overview

Neon Empire Casino is an interactive casino-themed website that allows users to play games using fictional credits. Players can enjoy Coin Flip and Slot Machines, place bets, and track their balance and statistics. The website features a Vegas Neon design with glowing colors, casino imagery, and interactive JavaScript functions. I chose this project because I wanted to combine web design with simple interactive games.
